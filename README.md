# Oxide_HomeLab
Testing Oxide environment on home lab equipment

I'll be using the setup by [Matthew Sanabria](https://matthewsanabria.com/) on [YouTube](https://youtu.be/qwXtS0-r1uQ?si=B8dbVxtm1Kt5Qcmf) to do my initial setup.  

The install will be on a [GMKtec NUCBOX K12](https://www.gmktec.com/products/gmktec-k12-amd-ryzen%E2%84%A2-7-h-255-mini-pc) upgraded with a more storage. 

- Hardware Specifications
    - AMD Ryzen 7 H 255
        - 8 Cores, 16 Threads
    - 64 GB RAM
    - 2 TiB NVME

Moved to using a **Dell R730xd** for installation.  I was unable to get network drivers to work properly.
